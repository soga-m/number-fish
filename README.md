🐟 NUMBER FISH

魚をマウスでドラッグして数字のボールを集め、目標値（TARGET）をぴったり作る計算ゲームです。

▶ 遊ぶ: https://soga-m.github.io/number-fish/

※ マウス操作のゲームのため、PCのブラウザで遊んでください（スマートフォン非対応）。

ゲームのルール
START を押すと、20秒のカウントダウンが始まります。
魚をクリックしたままドラッグして動かします。
魚が数字のボールに触れると、その数字を取得して合計に加算します。
合計が TARGET とぴったり一致すると、問題クリアです。
合計が TARGET を超えると OVER! になり、取得した数字がリセットされます。
3問クリアで ALL CLEAR!、時間切れで TIME UP! です。
「やり直し」で取得した数字を戻せ、終了後は RETRY で最初から遊べます。

問題は毎回ランダムに作られます。必ず正解の組み合わせが1つ含まれており、それ以外の組み合わせでも、合計が一致すれば正解です。

1. 問題の切り替え直後に、数字を誤取得してしまう問題

問題が切り替わった瞬間、魚の下にあったボールが、新しい数字のまま即座に取得されていました。切り替え時に魚と重なっているボールを「待機中」にして、一度離れるまで取得しない仕組みにしました。

2. 切り替え中の二重カウント

CLEAR! を表示している間も合計が目標値のままなので、マウスを動かすたびに正解数が増えていました。切り替え中を示すフラグを設けて、その間は取得と判定を止めています。

3. 当たり判定の見直し

最初は四角形同士の重なりで判定していたため、触れていない隣のボールまで取得されていました。魚とボールの中心同士の距離で判定する方式に変え、見た目どおりの接触になるよう調整しました。

4. 問題のランダム生成

目標値を2つの数に分けて正解ペアとし、残りをランダムな数字で埋めてシャッフルしています。ランダムな数字が大きすぎてすぐ OVER! にならないよう、上限を目標値に合わせています。
